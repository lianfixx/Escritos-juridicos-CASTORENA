# Aprendizajes y trazabilidad

## Qué puede convertirse en aprendizaje

Clasificar cada candidato como:

- observación documental;
- hipótesis de estilo;
- propuesta de redacción;
- corrección aprobada;
- regla jurídica verificada;
- dato personal o de configuración actualizable.

Sólo una instrucción expresa, una corrección identificada como aprobada o una regla jurídica verificada puede aplicarse como pauta. La autoría del cambio no se infiere por el nombre del archivo, el canal o la persona que lo compartió.

## Registro

| Campo | Contenido |
|---|---|
| Fecha | Fecha de la comparación o aprobación |
| Asunto anonimizado | Tipo de actuación y materia, sin datos del cliente |
| Fuente base | Archivo, versión y página o apartado |
| Antes | Fragmento mínimo necesario |
| Después | Fragmento aprobado o propuesto |
| Autoría | Confirmada, no confirmada o propuesta propia |
| Motivo | Jurídico, documental, estilo, claridad o estrategia |
| Estado | Observación, propuesta, aprobada, reemplazada o descartada |
| Alcance | Caso, tipo de escrito, materia o regla general |
| Evidencia | Fuente que permite sostenerla |

No guardar en este archivo nombres de clientes, domicilios, números de expediente, firmas ni documentación del caso.

## Reglas vigentes recuperadas

- Conservar el documento base y hacer cambios localizados.
- Distinguir hechos narrados, evidencia disponible, conclusión jurídica y punto pendiente.
- Explicar por separado los cambios materiales.
- No universalizar una fórmula, domicilio, lista de autorizados, fundamento o decisión de un caso.
- No atribuir intenciones o autoría de correcciones sin evidencia.
- Tratar el aprendizaje como persistente sólo después de guardarlo y validar la skill.

## Estado profesional actualizable

No atribuir al usuario título, cédula, poder o facultades reservadas sin una instrucción actual y evidencia adecuada. Los estados profesionales cambian: verificar el dato cuando sea decisivo, no deducirlo de que la persona egresó o colaboró en un escrito y no guardar datos personales fechados en un repositorio público.

## Persistencia

Si el usuario pide actualizar la skill, incorporar únicamente reglas sustentadas, ejecutar el validador, revisar que las referencias sigan siendo coherentes y verificar el commit remoto. Si el encargo no autoriza actualizarla, conservar el candidato en la entrega o nota de trabajo sin modificar el repositorio.
